# 정치 한 걸음

Streamlit 기반 정치·행정 학습 웹 애플리케이션입니다. 정치 교과 퀴즈, 실시간 정치인·당선인 자료, RSS 뉴스, 공공데이터 탐색, 국가기관·지방정부 조직 학습을 한곳에서 제공합니다.

## 저장소 구성

```text
main.py
Quiz.txt
NEWS.txt
requirements.txt
secrets_example.toml  # 설정 참고용 템플릿
지역코드_연계표.xlsx   # 지역명·기관코드·행정구역 코드 연계표(사용자 편집 가능)
tests/test_core.py    # Streamlit 없는 핵심 회귀 테스트
```

GitHub 저장소 최상위에 `main.py`, `Quiz.txt`, `NEWS.txt`, `requirements.txt`, `지역코드_연계표.xlsx`를 둡니다. Streamlit Cloud의 실행 파일은 `main.py`로 지정합니다. `지역코드_연계표.xlsx`는 `main.py`가 같은 폴더에서 읽으며, 지역명·API별 코드를 사용자가 GitHub에서 편집할 수 있습니다.

## 실행

```bash
python -m pip install -r requirements.txt
streamlit run main.py
```

`requirements.txt`는 요청에 따라 패키지 이름만 기록하고 버전은 고정하지 않습니다.

## API 인증키: 12개 변수명 / 실제 발급 키 10개

API 서비스는 12개이고 Secrets 변수명도 12개입니다. 다만 국회사무처의 국회의원 정보·본회의 표결·국회일정 3개 API는 열린국회정보에서 발급받은 동일한 인증키 1개를 공유합니다. 따라서 `ASSEMBLY_MEMBER_KEY`, `ASSEMBLY_VOTE_KEY`, `ASSEMBLY_SCHEDULE_KEY` 세 항목에는 같은 실제 키 값을 붙여 넣습니다. 나머지 선거관리위원회 2개, 행정안전부 5개, KOSIS 1개, VWorld 1개는 각각 해당 API에 발급된 키를 사용합니다. 총 10개의 서로 다른 발급 키 값입니다. 실제 키는 Streamlit Community Cloud의 앱 설정 → Secrets에만 등록합니다.

| API | Secrets 변수명 |
|---|---|
| 국회의원 정보 통합 | `ASSEMBLY_MEMBER_KEY` |
| 본회의 표결정보 | `ASSEMBLY_VOTE_KEY` |
| 국회일정 통합 | `ASSEMBLY_SCHEDULE_KEY` |
| 당선인 정보 | `NEC_WINNER_KEY` |
| 후보자 통합검색 | `NEC_CANDIDATE_KEY` |
| 공공서비스(혜택) 정보 | `MOIS_BENEFIT_KEY` |
| 기관별 공무원 정원 | `MOIS_STAFF_KEY` |
| 중앙행정기관별 하부기구 | `MOIS_SUBORG_KEY` |
| 기수별 지방의회의원 정수 | `MOIS_COUNCIL_KEY` |
| 행정동별 주민등록 인구 | `MOIS_POPULATION_KEY` |
| KOSIS 공유서비스 | `KOSIS_KEY` |
| VWorld 행정구역도 | `VWORLD_KEY` |

`secrets_example.toml`의 예시를 Streamlit Secrets에 붙여 넣은 뒤 실제 키로 교체합니다. 국회사무처 세 항목은 반드시 같은 값을 사용합니다. 이 세 항목 사이의 중복은 정상으로 허용하지만, 그 키를 선거·행정안전부·KOSIS·VWorld 항목에 재사용하면 중복으로 표시하고 요청을 차단합니다. 예시 문구는 미등록으로 판단합니다. 실제 인증키를 Python 코드나 GitHub 저장소에 넣지 마세요.

`APP.VWORLD_DOMAIN`에는 VWorld에 등록한 HTTPS 서비스 도메인을 입력합니다. WMTS 타일은 브라우저에서 직접 요청하므로 VWorld 키가 타일 요청 URL에 포함됩니다. VWorld 설정에서 허용 도메인을 Streamlit 앱 도메인으로 제한해야 합니다. 행정구역 경계는 WFS, 배경지도는 WMTS를 사용합니다. 신청된 WMS 권한은 현재 지도 화면에 별도 주제도 오버레이로 사용하지 않습니다.

## 화면·기능 구성

### 홈

- 왼쪽 메뉴와 오른쪽 메인 콘텐츠를 나란히 배치합니다.
- 오늘의 퀴즈는 `Quiz.txt` 문항 중 하나를 시작 버튼 없이 바로 표시합니다.
- 퀴즈 위에 “국회·선거·행정부 관련 자료를 바탕으로 한 퀴즈가 제공됩니다.”라는 안내를 둡니다.
- 아래에는 작은 국내·국제 뉴스 바로가기와 더 큰 공공자료 바로가기를 배치합니다.

### 정치 퀴즈·미니게임

- 교과 중심 문제는 사람이 직접 편집하는 `Quiz.txt`에서 읽어옵니다.
- 실시간 정치인 퀴즈는 국회의원·당선인 API의 실제 응답 자료를 사용합니다. 후보자 통합검색은 공식 명세의 이름 검색변수 `name`으로 조회하며, 여러 후보자의 경력 자료를 모아 비교형 경력 문제를 만들 수 있습니다. 경력 필드가 응답에 실제로 존재하고 서로 다른 후보자의 경력 자료가 충분할 때만 문제를 만들며, 동명이인 구분을 위해 선거·선거구·정당 정보를 함께 표시합니다. 임의의 인물 이력을 만들어 출제하지 않습니다. 실시간 자료 조회 도구는 문항 풀이 화면을 복잡하게 만들지 않도록 퀴즈 종류 선택 화면에서 제공합니다.
- 지방의회 정수만을 주제로 한 퀴즈는 만들지 않습니다. 지방의회 정수 데이터는 지방 지역 정보에서 참고 자료로 제공합니다.
- 오늘의 퀴즈·객관식·십자말풀이·빈칸 채우기 선택 구조를 유지합니다. 십자말풀이와 빈칸 채우기 상세 기능은 문제 형식과 규칙 확정 후 연결합니다.
- 퀴즈 종료 시 풀이 수·정답 수·정답률·주제별 오답 및 문제별 해설을 스크롤 가능한 결과 창에 표시합니다.

### 뉴스·속보

국내와 국제 기사를 좌우 2열로 배치하고 각 목록에 독립 스크롤을 제공합니다. 아래에 7개 언론사 바로가기를 둡니다. `NEWS.txt`에 등록된 RSS 주소만 사용하며 자동으로 다른 피드를 추가하지 않습니다.

현재 `NEWS.txt`의 13개 피드: KBS 월드 한국어, KBS 뉴스, 연합뉴스 정치·국제·전체, BBC World·Politics, CNN World·Politics, Reuters World, AP, AFP, France24.

### 정치 자료 탐색

12개 API를 6개 그룹으로 분류합니다: 입법부·국회(3), 선거(2), 행정부(3), 지방행정(2), 국가통계(1), 공간정보(1). 각 자료 상세 화면에는 자료 설명, 교과 연계, 공식 제공기관 링크, 조회 조건, 정리된 표와 원자료 다운로드 기능을 배치합니다. 긴 표와 목록에는 스크롤을 사용합니다.

### 공부하기

공부하기는 별도의 허브 화면에서 네 개의 2×2 카드(정부 조직·국회 조직·법원 조직·지방정부)를 먼저 보여주고, 각 카드에서 해당 학습 화면으로 이동합니다. 사이드바에도 공부하기 허브와 네 하위 화면 바로가기를 둡니다. 사이드바의 `정보 확인 가이드` 항목은 자료 출처와 기준 시점을 이해하는 화면으로 연결합니다. 각 기관 카드는 마우스오버 시 기관장 직위·핵심 업무·조직 규모와 참고 사항을 보여줍니다. 상하·소속 관계는 조직도 자체에서 확인하도록 툴팁에 중복하지 않으며, 기관 카드 클릭을 통한 별도 상세 페이지 이동은 후속 확장 대상으로 보류합니다.

- **정부 조직:** 정부조직관리정보시스템의 2026-10-02 기준 정부기구도를 참고합니다. 19부·6처·19청·6위원회 수치는 해당 기준일의 공식 자료에만 적용합니다. 정부디렉터리시스템 표준 API는 신청 대기 중이므로 사용하지 않습니다.
- **국회 조직:** 국회, 국회의장단, 위원회, 국회사무처, 국회 소속기관을 구분합니다.
- **법원 조직:** 대법원, 고등법원, 지방법원, 전문법원, 법원행정처 등 지원 조직을 보여줍니다. 도식은 이해를 위한 개요이며 법원 종류·심급·관할이 모두 동일한 상하 관계라는 뜻은 아닙니다.
- **지방정부:** 전국 행정구역 지도에서 현행 16개 광역자치단체 중 하나를 선택하고, 별도 화면에서 해당 지역의 시·군·구 경계를 확인해 기초자치단체 상세 화면으로 이동합니다. 시·군·구 선택 화면의 아래쪽에는 상위 광역자치단체의 지역 통계가 이어집니다. 상세 화면은 지역명과 유형 표시 → 지역 통계 → 지방 행정부·지방 의회 2열 조직도 순서로 구성합니다.

지방정부의 실제 조직도는 자치단체마다 다릅니다. 개별 지방정부 조직 API를 모두 신청하는 작업은 보류했으므로, 현재의 지방 행정부·지방 의회 도식은 실제 조직도를 복제한 것이 아닌 일반 구조 예시로 표시합니다.

### 지역 통계 항목과 해석

상세 화면은 시안에 맞춰 다음 7개 지표를 고정 순서로 보여줍니다. 값이 아직 연결되지 않았더라도 단위와 기준은 함께 표시하고, 수치 자체는 만들어 채우지 않고 “자료 연결 대기”로 표시합니다.

- 면적: VWorld 행정구역 경계 좌표로 계산한 참고 면적입니다. 공표된 법정·통계 면적을 대체하지 않습니다.
- 주민등록인구: 행정안전부 API 원자료를 조회합니다. 행정동·통·반 단위 여러 행을 단순 합산하지 않고, 단일 집계행과 필드가 확인된 경우에만 화면 요약값으로 표시합니다.
- 인구밀도: 확인된 주민등록인구와 면적이 모두 있을 때만 계산합니다.
- 출생아 수, 합계출산율, 고령인구 비율, 청년인구 비율: KOSIS 통계표·항목·지역 분류 코드·단위·기준시점이 응답에서 확인된 경우에만 해당 지표 카드를 채웁니다. KOSIS 원자료 조회 시 연결할 지표를 선택할 수 있으며, 항목명·단위·지역명이 맞지 않거나 같은 기준시점의 행이 여러 개면 수치를 카드에 넣지 않고 원자료 표만 표시합니다. 청년인구 비율은 원자료 명칭에서 19~34세 기준을 확인한 경우에만 청년기본법 기준 지표로 연결합니다.
- 합계출산율 단위는 가임여성 1명당 명입니다. 청년인구 비율은 기본적으로 청년기본법상 19~34세 기준을 표시하되, 지역 조례의 연령 기준이 다르면 해당 기준을 별도 표기해야 합니다.
- 지방의회의원 정수 API는 기수별·유형별 참고자료로만 제공합니다. 선택 지역의 현재 의석 수라고 단정하지 않습니다.

## 지역·행정기관 코드 연계표 (`지역코드_연계표.xlsx`)

이 파일은 지역 이름과 API별 코드 체계의 차이를 관리하는 GitHub 편집용 코드북입니다. `main.py`는 다음 시트를 직접 읽습니다.

- `광역_기초목록`: 2026년 10월 기준 광역자치단체 16개와 기초자치단체·행정시 이름, 각 API별 코드·명칭 입력란을 제공합니다. 세종특별자치시는 단층제이므로 앱의 지역 선택 흐름을 위해 내부적으로 상세 이동용 행을 하나 더 둡니다. 이 행은 실제 하위 기초자치단체가 있다는 뜻이 아닙니다.
- `행정동_법정동_매핑`: 230개 지역 단위 입력 템플릿과 2026-10-30 공지로 확인된 홍북읍 내포출장소 행을 포함해 총 231개 행을 제공합니다. 일반 지역 템플릿의 행정동명·법정동명·코드값은 비워 두었으며, 내포출장소는 공식 명칭과 시행일만 입력하고 숫자 코드는 비워 두었습니다. 한 행정동이 여러 법정동을 관할하면 관계별로 행을 복사해 각각 입력하세요.
- `VWorld_레이어`: 공식 WFS 레이어 ID와 속성 필드명. WFS는 `LT_C_ADSIDO_INFO`, `LT_C_ADSIGG_INFO`, `LT_C_ADEMD_INFO`, `LT_C_ADRI_INFO`를 사용하며, WMS 레이어 이름은 소문자입니다. 확인된 필드는 `ctprvn_cd`/`ctp_kor_nm`, `sig_cd`/`sig_kor_nm`, `emd_cd`/`emd_kor_nm`, `li_cd`/`li_kor_nm`입니다. 실제 지역 코드값은 WFS 응답에서 읽으므로 엑셀의 코드값은 임의로 채우지 않았습니다.
- `NEC_선거지역명`: `sdName`, `sggName`, `wiwName`에 대응할 수 있는 지역명 후보. 코드가 아니라 문자열 검색어이며, 선거 시점과 서비스별 명칭 차이가 있으므로 후보로만 사용합니다.
- `KOSIS_통계표별` 및 `KOSIS_지역분류_매핑`: 통계표·항목·기간·지역분류값 입력표. KOSIS의 `OBJ_L1` 등 지역분류 코드는 통계표마다 달라 공통 코드로 채우지 않습니다.
- `API_코드체계`: API별 요청변수, 코드 종류, 원자료, 확인 상태와 혼용 금지 원칙을 정리합니다.
- `행정개편_이력`, `확인된_코드예시`, `사용안내`: 기준일·개편 기록·검증된 예시와 코드 체계 설명

**서로 다른 코드 체계를 혼용하지 마세요.** MOIS 행정기관코드 `KiKcd_H`와 주민등록인구 API의 `admmCd`는 같은 행정기관코드 계열이므로 코드북에서는 `MOIS_admmCd(행정기관코드)`를 우선 사용하고 비어 있으면 `MOIS_KiKcd_H(행정동코드)`를 보조로 읽습니다. 반면 MOIS 법정동코드 `KiKcd_B`, 행정기관-법정동 연결 `KiKmix`, VWorld WFS 코드, NEC 지역명 요청변수, KOSIS 통계표별 지역분류값은 서로 대체할 수 없습니다. 특히 법정동코드를 주민등록인구 API의 `admmCd` 자리에 넣으면 안 됩니다.

### 코드북 기준일과 행정구역 개편

코드북은 현재 확인한 행정안전부의 **2026-10-30 기준 공지**를 최신 변경 공지로 반영했습니다. 해당 공지의 주소코드 첨부파일은 `jscode20261026.zip`이며, 내부 파일은 `KiKcd_H.20261026`(행정기관·행정동), `KiKcd_B.20261026`(법정동 주소), `KiKmix.20261026`(행정기관과 관할 법정동 연결)입니다. <https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=130674>

확인한 개편 이력은 다음과 같습니다.

- 2026-10-30 충남 홍성군: 홍북읍 내포출장소 신설. 법정동(리) 코드는 변동이 없다고 명시되어 있어 행정기관 코드만 원본에서 확인하도록 했습니다.
- 2026-10-12 평택시: 고덕동 행정기관 폐지, 고덕1동·고덕2동 신설. 공지에는 법정동(리) 코드 변동이 없다고 명시되어 있습니다. 비전동·세교동 관할이 통복동에서 동삭동으로 변경된 사항도 별도 기록했습니다.
- 2026-09-30 대구 달성군: 구지면 폐지, 구지읍 신설. 관할 리의 법정동 코드도 폐지·신설로 기재되어 있으므로 기존 숫자 코드를 복사하면 안 됩니다.
- 2026-07-20 세종특별자치시: 집현동 행정동 신설, 법정동(리) 코드 변동 없음.
- 2026-07-01: 전남광주통합특별시 출범 및 인천 자치구 등 행정구역 개편.

현재 이 환경에서는 행정안전부 2026-10-30 공지의 게시일·변경 내용·첨부파일명과 코드 파일의 역할은 확인했지만, 2MB ZIP 원본을 내려받아 내부의 모든 숫자 코드를 직접 대조하지는 못했습니다. 그러므로 **실제 MOIS 행정기관·법정동 코드 숫자는 비워 두었습니다.** 빈칸은 누락된 임의값이 아니라 원본 파일 대조가 끝나지 않았다는 뜻입니다. 사용자가 공식 ZIP을 내려받아 코드값을 확인한 뒤 입력할 수 있도록 템플릿과 출처를 넣었습니다.

GitHub 웹 화면에서 엑셀 셀을 직접 편집할 수는 없으므로, 저장소의 `지역코드_연계표.xlsx`를 내려받아 Excel 등에서 수정한 뒤 같은 파일명으로 GitHub에 다시 업로드하면 됩니다. 시트명·열 제목은 유지하고, 코드는 앞자리 0이 사라지지 않도록 셀 형식을 텍스트로 유지하세요. Streamlit은 저장소의 파일을 읽고, 앱 재실행 시 수정된 파일을 다시 불러옵니다.

## API 요청 규격의 미확정 사항

키가 등록되어 있어도 모든 API가 실제 인증키로 호출되어 성공하는지까지 확인된 것은 아닙니다. 국회일정·지방의회의원 정수는 각 활용가이드에서 상세 요청 주소 또는 요청변수를 확인해야 하므로 미확정 값은 임의로 전송하지 않습니다. 후보자 통합검색의 이름 검색변수 `name`은 공식 명세에서 확인해 코드에 반영했습니다. 행정동별 주민등록 인구 API는 공식 요청주소 `https://apis.data.go.kr/1741000/admmPpltnHhStus`와 `admmCd`, `srchFrYm`, `srchToYm`, `lv`, `regSeCd`, `type`, `numOfRows`, `pageNo` 변수를 사용합니다. 한 번의 조회 기간은 최대 3개월입니다. 광역자치단체는 단일 시도(lv=5), 기초자치단체는 단일 시군구(lv=6)로 조회하며 주민등록 행정기관코드는 VWorld 법정구역 코드와 다를 수 있어 별도 확인이 필요합니다. 참고: https://www.data.go.kr/data/15108065/openapi.do

KOSIS 통계목록은 공식 개발 가이드 화면의 입력 설명에 `parentId`가 표시되지만, 실제 GET 예제 코드와 샘플 호출 URL은 `parentListId`를 전송하므로 앱에서는 실행 예제와 일치하는 `parentListId`를 사용합니다. 지방통계 탐색 화면은 e-지방지표의 주제별·지역별·테마별 3개 유형으로 제한합니다. KOSIS 지역별 지표는 통계표 ID·항목 ID·지역 분류 코드·단위가 응답에서 확인된 경우에만 지역 통계 카드에 연결합니다. 참고: https://kosis.kr/openapi/devGuide/devGuide_0101List.do

공공서비스 목록 API는 공식 명세에 서비스명 LIKE 검색변수가 없으므로, 목록 요청 후 조회한 페이지(최대 100건) 안에서 서비스명·요약·지원대상·기관명 등을 로컬 검색합니다. 검색 범위가 전체 데이터가 아니라 현재 선택한 페이지임을 화면에 안내합니다. 참고: https://www.data.go.kr/data/15113968/openapi.do

## `Quiz.txt` 형식

`Quiz.txt`는 사람이 읽고 직접 문제를 수정할 수 있는 텍스트 파일입니다. 문제마다 분야, 문제, 선택지, 정답 번호, 해설을 정해진 형식으로 적습니다. 파서는 잘못된 선택지·정답·중복 문제를 진단하고 유효하지 않은 문항을 출제에서 제외합니다.

## `NEWS.txt` 형식

```text
국내|언론사 표시명|RSS 주소
국제|언론사 표시명|RSS 주소
```

주소는 사용자가 제공한 13개 피드만 유지합니다.
