# 정치 한 걸음 — 심층 검수·수정본 (업로드된 1차 개발본)

이 폴더는 사용자가 제공한 `politics_one_step_phase1.zip`을 바탕으로 코드 검토, 오류 수정, 회귀 테스트를 진행한 버전입니다. 원본 ZIP은 변경하지 않았습니다.

## 파일 구성

```text
main.py
Quiz.txt
NEWS.txt
requirements.txt
secrets_example.toml
README.md
CODE_REVIEW.md
tests/test_core.py
.gitignore
```

GitHub 저장소의 최상위에 위 파일들을 배치하고 Streamlit 실행 파일을 `main.py`로 지정합니다. 파일명 대소문자를 유지하세요.

## 실행

```bash
python -m pip install -r requirements.txt
streamlit run main.py
```

회귀 테스트는 앱 배포용 패키지와 분리해 실행합니다.

```bash
python -m pip install pytest
pytest -q
```

`requirements.txt`는 사용자가 요청한 대로 패키지 이름만 포함하며 버전 번호는 고정하지 않았습니다.

## 앱 구성 및 현재 범위

- **메인 화면:** 오늘의 퀴즈, 자료 바로가기, 뉴스 이동.
- **퀴즈:** `Quiz.txt`의 객관식 문제, 진행률, 정답 제출, 결과 요약과 오답 주제 표시.
- **미니게임:** 오늘의 퀴즈·객관식 선택 화면. 십자말풀이와 빈칸 채우기는 메뉴와 안내만 있으며 실제 게임 생성 기능은 미구현입니다.
- **실시간 인물 퀴즈:** 국회의원·당선인 API 응답에 존재하는 자료를 바탕으로 문제를 생성합니다. 실제 API 응답에서 충분한 인물 데이터가 있어야 시작할 수 있습니다.
- **뉴스:** `NEWS.txt`에 등록된 RSS만 수집합니다. 국내·국제 피드를 병렬 처리하고 각 목록에 독립 스크롤을 제공합니다.
- **정치 자료 탐색:** 국회·선거·행정부·지방행정·KOSIS·VWorld 등 총 12개 자료 항목의 설명, 조회 폼, 표와 다운로드 기능을 제공합니다.
- **공부하기:** 정부·국회·법원 기초 조직 화면, 기관별 상세 설명, 시도·시군구 경계 기반 지방정부 탐색 화면을 포함합니다.
- **지도:** VWorld WFS로 행정구역 경계를 요청하지만, 현재 Folium 바탕지도는 CartoDB Positron을 사용합니다. VWorld WMS/WMTS 바탕지도로 전환한 구현은 아닙니다.

> 범위 주의: 이 수정본의 원본은 `phase1.zip`입니다. 별도 대화에서 만든 후반부 개발 ZIP의 모든 변경 사항이나 기초자치단체별 지방정부·지방의회 상세 조직도가 통합된 최종본이라고 단정할 수 없습니다. 후반부 최종본을 하나로 합치려면 두 코드의 실제 차이를 대조해야 합니다.

## 데이터 파일

### `Quiz.txt`

각 문제를 `[문제]` 블록으로 작성하며, 문제 사이에는 `---`를 둡니다. 선택지는 `|`로 구분하고 정답은 1부터 시작하는 선택지 번호입니다. 앱은 누락, 중복 문제, 중복 선택지, 잘못된 정답 번호를 진단합니다.

### `NEWS.txt`

한 줄에 하나씩 아래 형식을 사용합니다.

```text
국내|언론사 표시명|RSS 주소
국제|언론사 표시명|RSS 주소
```

이번 전달본은 사용자가 이전에 지정한 13개 피드만 유지합니다. 새 피드를 임의로 추가하지 않았습니다.

## Streamlit Secrets

`secrets_example.toml`은 구조 참고용입니다. 실제 값은 Streamlit Community Cloud의 **App settings → Secrets**에 설정하세요. 실제 키를 GitHub에 올리면 안 됩니다.

필수 인증키 그룹:

- `API_KEYS.OPENASSEMBLY_KEY`
- `API_KEYS.DATA_GO_KR_KEY`
- `API_KEYS.KOSIS_KEY`
- `API_KEYS.VWORLD_KEY`

추가 설정이 필요한 항목:

- 국회일정 API의 상세 요청 주소 또는 API 코드
- 후보자 이름 검색변수
- 행정동 인구 API의 상세 요청 주소와 통계년월·행정기관코드 변수명
- 지방의회의원 정수 API의 상세 요청 주소
- VWorld에 등록한 실제 서비스 도메인

공공서비스(혜택) 목록은 공식 정부24 `serviceList` 주소를 기본값으로 사용합니다. 사용자가 직접 API URL을 변경할 필요는 없습니다.

## API 연결 현황 — 실제 성공으로 오인하지 않기

코드에 어댑터가 있다는 사실과 외부 서버에서 자료를 실제로 받아왔다는 사실은 다릅니다.

- 국회의원 정보·본회의 표결, 당선인, 기관별 공무원 정원, 중앙행정기관 하부기구: 코드에 기본 요청 경로가 있으나 실인증키를 이용한 호출은 미검증.
- 국회일정: 상세 주소/API 코드 설정 필요.
- 후보자 통합검색: 이름 검색변수 설정 필요.
- 공공서비스(혜택): 정부24 공식 `serviceList` 경로와 `page`, `perPage`, `returnType`, 서비스명 LIKE 조건을 사용하도록 구성.
- 지방의회의원 정수·행정동 인구: 상세 주소 미설정. 인구 API는 행정기관코드와 통계년월 변수명을 확인하기 전까지 요청하지 않도록 차단.
- KOSIS: 공식 조회 흐름을 사용하되 통계표·기관·항목·분류 코드는 사용자가 해당 통계표에서 확인해 입력해야 함.
- VWorld: WFS 경계 요청은 구현되어 있으나 실제 인증·도메인·레이어·응답 속성은 배포 환경에서 확인 필요.

지방의회 의원 정수 통계는 기수별·유형별 집계입니다. 특정 자치단체의 현재 의원 정수로 곧바로 해석하지 않도록 화면에 주의문을 두었습니다. 행정동 인구 API도 통·반 단위 자료일 수 있으므로 단순 합산을 전체 지역 인구로 오인하면 안 됩니다.

## 주요 검수 한계

현재 작업 컨테이너에는 `streamlit`, `streamlit-folium`, `feedparser`가 설치되어 있지 않았습니다. 따라서 실제 Streamlit 서버·브라우저 화면·실시간 RSS/API/VWorld 호출은 확인하지 못했습니다. `tests/test_core.py`는 Streamlit 대체 모듈과 모의 응답을 사용해 핵심 함수의 검증 가능한 부분을 회귀 테스트합니다.

자세한 수정 내역, 통과한 테스트, 미해결 항목 및 배포 전 체크리스트는 `CODE_REVIEW.md`를 참고하세요.
