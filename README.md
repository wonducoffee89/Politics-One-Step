# 정치 한 걸음

Streamlit 기반 정치·행정 학습 웹 애플리케이션입니다. 정치 교과 퀴즈, 실시간 정치인·당선인 자료, RSS 뉴스, 공공데이터 탐색, 국가기관·지방정부 조직 학습을 한곳에서 제공합니다.

## 저장소 구성

```text
main.py
Quiz.txt
NEWS.txt
requirements.txt
secrets_example.toml  # 설정 참고용 템플릿
tests/test_core.py    # Streamlit 없는 핵심 회귀 테스트
```

GitHub 저장소 최상위에 `main.py`, `Quiz.txt`, `NEWS.txt`, `requirements.txt`를 둡니다. Streamlit Cloud의 실행 파일은 `main.py`로 지정합니다.

## 실행

```bash
python -m pip install -r requirements.txt
streamlit run main.py
```

`requirements.txt`는 요청에 따라 패키지 이름만 기록하고 버전은 고정하지 않습니다.

## API 인증키: 12개 API별 개별 키

총 12개 API는 각각 독립된 인증키를 사용합니다. 같은 제공 포털에서 발급받았다는 이유로 키를 합치거나 재사용하지 않습니다. 실제 키는 Streamlit Community Cloud의 앱 설정 → Secrets에만 등록합니다.

| API | Secrets 변수명 |
|---|---|
| 국회의원 정보 통합 | `ASSEMBLY_MEMBER_KEY` |
| 본회의 표결정보 | `ASSEMBLY_VOTE_KEY` |
| 국회일정 통합 | `ASSEMBLY_SCHEDULE_KEY` |
| 당선인 정보 | `NEC_WINNER_KEY` |
| 후보자 통합검색 | `NEC_CANDIDATE_KEY` |
| 공공서비스(혜택) 정보 | `MOIS_BENEFIT_KEY` |
| 기관별 공무원 정원 | `MOIS_STAFF_KEY` |
| 중앙행정기관별 하부기구 | `MOIS_SUBORG_KEY` |
| 기수별 지방의회의원 정수 | `MOIS_COUNCIL_KEY` |
| 행정동별 주민등록 인구 | `MOIS_POPULATION_KEY` |
| KOSIS 공유서비스 | `KOSIS_KEY` |
| VWorld 행정구역도 | `VWORLD_KEY` |

`secrets_example.toml`의 12개 예시 값을 각각 실제 발급키로 교체한 뒤 Secrets 입력란에 붙여 넣습니다. 예시 문구를 그대로 두면 앱에서 미등록으로 판단합니다. 다른 API의 키와 값이 중복되면 해당 항목은 중복으로 표시하고 요청을 차단합니다. 실제 인증키를 Python 코드나 GitHub 저장소에 넣지 마세요.

`APP.VWORLD_DOMAIN`에는 VWorld에 등록한 HTTPS 서비스 도메인을 입력합니다. WMTS 타일은 브라우저에서 직접 요청하므로 VWorld 키가 타일 요청 URL에 포함됩니다. VWorld 설정에서 허용 도메인을 Streamlit 앱 도메인으로 제한해야 합니다. 행정구역 경계는 WFS, 배경지도는 WMTS를 사용합니다. 신청된 WMS 권한은 현재 지도 화면에 별도 주제도 오버레이로 사용하지 않습니다.

## 화면·기능 구성

### 홈

- 왼쪽 메뉴와 오른쪽 메인 콘텐츠를 나란히 배치합니다.
- 오늘의 퀴즈는 `Quiz.txt` 문항 중 하나를 시작 버튼 없이 바로 표시합니다.
- 퀴즈 위에 “국회·선거·행정부 관련 자료를 바탕으로 한 퀴즈가 제공됩니다.”라는 안내를 둡니다.
- 아래에는 작은 국내·국제 뉴스 바로가기와 더 큰 공공자료 바로가기를 배치합니다.

### 정치 퀴즈·미니게임

- 교과 중심 문제는 사람이 직접 편집하는 `Quiz.txt`에서 읽어옵니다.
- 실시간 정치인 퀴즈는 국회의원·당선인 API의 실제 응답 자료를 사용합니다. 후보자 통합검색으로 여러 후보자의 경력 자료를 모아 비교형 경력 문제도 만들 수 있습니다. 후보자 이름 검색변수는 활용가이드에서 확인해 `API_CODES.CANDIDATE_NAME_PARAM`에 입력해야 합니다. 경력 필드가 응답에 실제로 존재하고 서로 다른 후보자의 경력 자료가 충분할 때만 문제를 만들며, 동명이인 구분을 위해 선거·선거구·정당 정보를 함께 표시합니다. 임의의 인물 이력을 만들어 출제하지 않습니다.
- 지방의회 정수만을 주제로 한 퀴즈는 만들지 않습니다. 지방의회 정수 데이터는 지방 지역 정보에서 참고 자료로 제공합니다.
- 오늘의 퀴즈·객관식·십자말풀이·빈칸 채우기 선택 구조를 유지합니다. 십자말풀이와 빈칸 채우기 상세 기능은 문제 형식과 규칙 확정 후 연결합니다.
- 퀴즈 종료 시 풀이 수·정답 수·정답률·주제별 오답 및 문제별 해설을 스크롤 가능한 결과 창에 표시합니다.

### 뉴스·속보

국내와 국제 기사를 좌우 2열로 배치하고 각 목록에 독립 스크롤을 제공합니다. 아래에 7개 언론사 바로가기를 둡니다. `NEWS.txt`에 등록된 RSS 주소만 사용하며 자동으로 다른 피드를 추가하지 않습니다.

현재 `NEWS.txt`의 13개 피드: KBS 월드 한국어, KBS 뉴스, 연합뉴스 정치·국제·전체, BBC World·Politics, CNN World·Politics, Reuters World, AP, AFP, France24.

### 정치 자료 탐색

12개 API를 6개 그룹으로 분류합니다: 입법부·국회(3), 선거(2), 행정부(3), 지방행정(2), 국가통계(1), 공간정보(1). 각 자료 상세 화면에는 자료 설명, 교과 연계, 공식 제공기관 링크, 조회 조건, 정리된 표와 원자료 다운로드 기능을 배치합니다. 긴 표와 목록에는 스크롤을 사용합니다.

### 공부하기

공부하기는 별도의 허브 화면에서 네 개의 2×2 카드(정부 조직·국회 조직·법원 조직·지방정부)를 먼저 보여주고, 각 카드에서 해당 학습 화면으로 이동합니다. 사이드바에도 공부하기 허브와 네 하위 화면 바로가기를 둡니다. 사이드바의 `정보 확인 가이드` 항목은 자료 출처와 기준 시점을 이해하는 화면으로 연결합니다. 각 기관 카드는 마우스오버 시 기관장 직위·핵심 업무·조직 규모와 참고 사항을 보여줍니다. 상하·소속 관계는 조직도 자체에서 확인하도록 툴팁에 중복하지 않으며, 기관 카드 클릭을 통한 별도 상세 페이지 이동은 후속 확장 대상으로 보류합니다.

- **정부 조직:** 정부조직관리정보시스템의 2026-10-02 기준 정부기구도를 참고합니다. 19부·6처·19청·6위원회 수치는 해당 기준일의 공식 자료에만 적용합니다. 정부디렉터리시스템 표준 API는 신청 대기 중이므로 사용하지 않습니다.
- **국회 조직:** 국회, 국회의장단, 위원회, 국회사무처, 국회 소속기관을 구분합니다.
- **법원 조직:** 대법원, 고등법원, 지방법원, 전문법원, 법원행정처 등 지원 조직을 보여줍니다. 도식은 이해를 위한 개요이며 법원 종류·심급·관할이 모두 동일한 상하 관계라는 뜻은 아닙니다.
- **지방정부:** 전국 행정구역 지도에서 17개 광역자치단체 중 하나를 선택하고, 별도 화면에서 해당 지역의 시·군·구 경계를 확인해 기초자치단체 상세 화면으로 이동합니다. 시·군·구 선택 화면의 아래쪽에는 상위 광역자치단체의 지역 통계가 이어집니다. 상세 화면은 지역명과 유형 표시 → 지역 통계 → 지방 행정부·지방 의회 2열 조직도 순서로 구성합니다.

지방정부의 실제 조직도는 자치단체마다 다릅니다. 개별 지방정부 조직 API를 모두 신청하는 작업은 보류했으므로, 현재의 지방 행정부·지방 의회 도식은 실제 조직도를 복제한 것이 아닌 일반 구조 예시로 표시합니다.

### 지역 통계 항목과 해석

상세 화면은 시안에 맞춰 다음 7개 지표를 고정 순서로 보여줍니다. 값이 아직 연결되지 않았더라도 단위와 기준은 함께 표시하고, 수치 자체는 만들어 채우지 않고 “자료 연결 대기”로 표시합니다.

- 면적: VWorld 행정구역 경계 좌표로 계산한 참고 면적입니다. 공표된 법정·통계 면적을 대체하지 않습니다.
- 주민등록인구: 행정안전부 API 원자료를 조회합니다. 행정동·통·반 단위 여러 행을 단순 합산하지 않고, 단일 집계행과 필드가 확인된 경우에만 화면 요약값으로 표시합니다.
- 인구밀도: 확인된 주민등록인구와 면적이 모두 있을 때만 계산합니다.
- 출생아 수, 합계출산율, 고령인구 비율, 청년인구 비율: KOSIS 통계표·항목·지역 분류 코드·단위·기준시점이 응답에서 확인된 경우에만 해당 지표 카드를 채웁니다. KOSIS 원자료 조회 시 연결할 지표를 선택할 수 있으며, 항목명·단위·지역명이 맞지 않거나 같은 기준시점의 행이 여러 개면 수치를 카드에 넣지 않고 원자료 표만 표시합니다. 청년인구 비율은 원자료 명칭에서 19~34세 기준을 확인한 경우에만 청년기본법 기준 지표로 연결합니다.
- 합계출산율 단위는 가임여성 1명당 명입니다. 청년인구 비율은 기본적으로 청년기본법상 19~34세 기준을 표시하되, 지역 조례의 연령 기준이 다르면 해당 기준을 별도 표기해야 합니다.
- 지방의회의원 정수 API는 기수별·유형별 참고자료로만 제공합니다. 선택 지역의 현재 의석 수라고 단정하지 않습니다.

## API 요청 규격의 미확정 사항

키가 등록되어 있어도 상세 요청 URL과 변수까지 확인된 것은 아닙니다. 국회일정·후보자 이름 검색변수·지방의회의원 정수·행정동 인구의 상세 요청 규격은 각 계정의 활용가이드와 대조해 설정해야 합니다. 미확정 값은 임의로 호출하지 않도록 빈 설정 상태로 둡니다. KOSIS 통계목록은 현재 공개된 개발 가이드의 요청변수 `parentId`를 사용합니다. 목록 유형은 국내통계·지역통계 및 e-지방지표(주제별·지역별·테마별)를 탐색할 수 있습니다. KOSIS 지역별 지표는 지표별 통계표 ID·항목 ID·지역 분류 코드·단위가 응답에서 확인된 경우에만 지역 통계 카드에 연결합니다. 참고: https://kosis.kr/openapi/devGuide/devGuide_0101List.do

## `Quiz.txt` 형식

`Quiz.txt`는 사람이 읽고 직접 문제를 수정할 수 있는 텍스트 파일입니다. 문제마다 분야, 문제, 선택지, 정답 번호, 해설을 정해진 형식으로 적습니다. 파서는 잘못된 선택지·정답·중복 문제를 진단하고 유효하지 않은 문항을 출제에서 제외합니다.

## `NEWS.txt` 형식

```text
국내|언론사 표시명|RSS 주소
국제|언론사 표시명|RSS 주소
```

주소는 사용자가 제공한 13개 피드만 유지합니다.

## 검증·배포 메모

Streamlit이 설치되지 않은 환경에서는 문법 검사와 Streamlit 대체 객체를 이용한 핵심 로직 테스트까지만 수행할 수 있습니다. 실제 인증키를 이용한 12개 API 호출, VWorld 지도 타일의 브라우저 로딩, Streamlit Cloud에서의 전체 페이지 렌더링은 배포 후 확인해야 합니다. 모의 테스트 통과를 실제 서비스 연결 성공으로 해석하지 않습니다.
