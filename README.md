# 정치 한 걸음 — 버전 3

정치에 익숙하지 않은 학생과 청년이 정치 제도와 실제 현안을 쉽게 접하고, 공공자료와 뉴스의 출처를 직접 확인하며 스스로 판단할 수 있도록 돕는 Streamlit 학습 웹앱입니다.

## 1. GitHub 저장소 구성

```text
main.py
Quiz.txt
NEWS.txt
requirements.txt
secrets_example.toml       # Secrets 참고용 템플릿(실제 키를 넣지 않음)
지역코드_연계표.xlsx        # 사용자가 수정하는 지역·API 코드북
tests/
  test_core.py             # 개발·회귀 테스트용
```

Streamlit Community Cloud의 실행 파일은 `main.py`로 지정합니다. 위 파일은 저장소 최상위에 두고, `tests` 폴더도 함께 올리면 이후 코드 변경 시 회귀 테스트를 실행할 수 있습니다.

## 2. API 인증키 — Secrets에는 4개만 입력

12개 API 서비스를 4개 발급처별 인증키로 호출합니다. API별 요청 주소와 요청 매개변수는 `main.py`의 `API_ITEMS` 및 각 호출 어댑터에 작성되어 있습니다. TOML에 API 주소나 매개변수명을 추가할 필요가 없습니다.

Streamlit Community Cloud → 앱의 **Settings → Secrets**에 다음 구조를 붙여 넣고 실제 인증키 값으로 교체합니다.

```toml
[API_KEYS]
ASSEMBLY_KEY = "열린국회정보_인증키"
DATA_GO_KR_KEY = "공공데이터포털_개인인증키"
KOSIS_KEY = "KOSIS_인증키"
VWORLD_KEY = "VWorld_인증키"

[APP]
VWORLD_DOMAIN = "https://실제-배포-도메인"
```

| Secrets 변수 | 사용 API | 공유 방식 |
|---|---|---|
| `ASSEMBLY_KEY` | 국회의원 정보·본회의 표결·국회일정 | 국회사무처 3개 API가 같은 키 사용 |
| `DATA_GO_KR_KEY` | 당선인·후보자·공공서비스·공무원 정원·하부기구·지방의회 정수·주민등록 인구 | 공공데이터포털 7개 API가 같은 개인 키 사용 |
| `KOSIS_KEY` | KOSIS 공유서비스 | 단독 |
| `VWORLD_KEY` | VWorld WMTS/WFS | 단독 |

실제 인증키는 `main.py`, `README.md`, `secrets_example.toml` 또는 GitHub 저장소에 입력하지 않습니다. **국회사무처 3개 항목에 같은 키를 반복 입력하거나 공공데이터포털 7개 항목마다 별도 키를 넣을 필요가 없습니다.** 각 발급처에서 받은 키 하나씩, 총 4개만 Secrets에 등록하면 됩니다.

`VWORLD_DOMAIN`은 인증키가 아니라 VWorld에 등록한 서비스 도메인입니다. WMTS 지도 타일은 브라우저에서 직접 요청하므로 VWorld의 허용 도메인 설정에 실제 Streamlit 앱 주소를 등록해야 합니다.

## 3. 화면과 기능

### 홈

- 좌측 메뉴와 우측 콘텐츠 영역을 사용합니다.
- 오늘의 문제와 선택지를 시작 버튼 없이 표시합니다.
- 정답 제출 후 정오와 해설을 확인하고 전체 정치 퀴즈로 이동할 수 있습니다.
- 전체 오늘의 퀴즈를 완료하면 홈에도 `오늘의 퀴즈 완료!` 상태를 표시하며, 완료한 문제를 다시 출제하지 않습니다.
- 국내·국제 뉴스 바로가기와 6개 공공자료 바로가기를 제공합니다.

### 정치 퀴즈

- 교과 중심 퀴즈는 `Quiz.txt`에서 불러옵니다. GitHub에서 텍스트 파일만 수정해 문제를 추가·삭제할 수 있습니다.
- 오늘의 퀴즈는 한 문제씩 진행합니다. 제출 직후 정답·오답과 해설을 보여 주며, 사용자가 `다음 문제`를 눌러야 다음 문항으로 이동합니다.
- 마지막 문항 이후 `오늘의 결과 보기`를 누르면 결과 대화상자가 열립니다. 결과를 닫으면 퀴즈 페이지에 `오늘의 퀴즈 완료!`가 표시됩니다.
- 결과에는 풀이 수, 정답 수, 정답률, 주제별 오답, 문제별 정답·해설·출처가 표시됩니다.
- 실시간 정치인 퀴즈는 승인된 국회의원·당선인·후보자 API가 실제로 반환한 자료만 사용합니다. 후보자 경력 퀴즈는 둘 이상의 인물에 대해 비교 가능한 경력 필드가 응답에 포함될 때만 출제합니다. API 응답에 없는 경력을 만들어 문제에 사용하지 않습니다.
- 이전 피드백에 따라 **미니게임(십자말풀이·빈칸 채우기)은 메뉴와 진행 기능에서 제거**했습니다. 별도 객관식 연습과 실시간 인물 자료 퀴즈는 유지합니다.

### 뉴스·속보

- `NEWS.txt`에 등록된 RSS 13개만 수집합니다. 다른 피드를 자동으로 추가하지 않습니다.
- 국내·국제 기사를 좌우 2열로 표시하며 각 영역은 독립 스크롤을 사용합니다.
- 종합·국내·국제 선택, 언론사 필터, 제목·요약 키워드 검색, 최신순·오래된순·언론사순 정렬을 제공합니다.
- 기사 카드에 언론사 파비콘과 언론사별 파스텔 색을 표시하고, 제목은 원문으로 연결합니다.
- 하단 언론사 바로가기는 `NEWS.txt`의 언론사 표시명을 기준으로 자동 생성합니다. 동일 언론사의 여러 RSS는 `NEWS.txt`에서 같은 표시명을 사용하면 하나의 검색·바로가기 항목으로 묶입니다. 새 언론사 이름을 추가하면 해당 언론사 필터와 하단 바로가기도 자동으로 생성됩니다. URL만 추가하면 되며 Python 코드를 수정할 필요는 없습니다.

현재 기본 RSS 13개는 7개 언론사 그룹으로 표시합니다: KBS, 연합뉴스, BBC, CNN, Reuters, AP, AFP·France24. RSS 주소 자체는 기존에 사용자가 지정한 13개를 유지했습니다.

`NEWS.txt` 작성 형식:

```text
국내|언론사 표시명|RSS 주소
국제|언론사 표시명|RSS 주소
```

같은 언론사의 피드를 여러 개 등록할 때는 `언론사 표시명`을 동일하게 작성합니다.

### 정치 자료 탐색

12개 API를 6개 기관·자료 그룹으로 나눕니다: 국회 정보, 선거 정보, 정부 정보, 지방정부 정보, 국가 통계, 공간정보. 각 그룹은 기관 로고/파비콘과 짧은 부제를 표시하고, 개별 API 카드에는 별도 큰 아이콘을 반복하지 않습니다. 상세 화면에서 자료 설명, 교과 연계, 공식 출처, 조회 조건, 정리된 표 및 다운로드 기능을 제공합니다.

### 공부하기와 조직도

- 사이드바의 `공부하기`는 이동 버튼이 아니라 구분용 섹션 제목입니다.
- 정부·국회·법원·지방정부 화면으로 이동할 수 있습니다.
- 정부조직도는 부·처·청·위원회 목록을 펼쳐서 확인할 수 있습니다. 기관 수와 기준 목록이 맞지 않는 경우 `코드 최신화 필요` 안내를 표시합니다. 정부디렉터리시스템 API는 신청 대기 상태이므로 사용하지 않습니다.
- 조직도 툴팁은 기관장 직위, 주요 업무, 조직 규모와 참고 사항을 표시합니다. 현재 승인된 12개 API에는 기관별 현직 기관장 이름을 제공하는 인사정보 데이터가 확인되지 않았으므로 이름은 임의로 표시하지 않고 미연동 상태로 안내합니다. 정부디렉터리 또는 별도 공식 인사정보 API 승인 후 연동할 수 있습니다.
- 지방정부 화면은 전국 지도 → 광역자치단체 → 기초자치단체 → 상세 화면의 순서로 탐색합니다. 지역 통계와 지방 행정부·지방의회 구조를 함께 표시합니다.
- 실제 지역별 조직도 자료는 전국 단일 API로 확보하지 않았습니다. 따라서 지방 행정부·지방의회 도식은 실제 해당 지역의 정확한 조직도를 복제한 것이 아니라 일반 구조 예시라고 표시합니다.

### 시뮬레이션

사이드바의 시뮬레이션 화면은 외부 Streamlit 앱을 iframe으로 삽입할 수 있게 구성했습니다. 친구 앱 주소가 아직 제공되지 않아 기본 `SIMULATION_APP_URL`은 비어 있습니다. 나중에 `main.py` 상단의 해당 상수에 HTTPS 주소를 입력하면 화면에 삽입을 시도합니다. 상대 앱이 iframe 삽입을 허용하지 않으면 브라우저 보안 정책으로 표시되지 않을 수 있습니다.

## 4. 지역코드 연계표 (`지역코드_연계표.xlsx`)

`main.py`는 저장소 최상위의 엑셀 파일을 읽습니다. 지역명 및 API별 코드가 서로 다른 시트에 있으므로 코드를 임의로 다른 열에 복사하지 마세요. 특히 MOIS 행정기관코드·법정동코드·VWorld 코드·NEC 검색용 지역명·KOSIS 통계표별 지역분류 코드는 서로 대체할 수 없습니다.

엑셀을 수정하려면 GitHub의 파일을 내려받아 Excel에서 수정한 뒤, 동일한 파일명 `지역코드_연계표.xlsx`로 저장소 최상위에 다시 올립니다. 시트명과 열 제목을 유지하고, 앞자리에 0이 들어가는 코드는 셀 형식을 텍스트로 저장합니다. 숫자 코드가 빈칸인 곳은 공식 자료에서 확인해 직접 입력해야 하며, 앱은 빈 코드를 추측하지 않습니다.

## 5. 정부조직 현직자 정보의 한계

조직도에서 기관장 직위와 역할은 표시하지만, 현직 기관장 이름은 현재 승인된 API로 확보되지 않았습니다. 이름이 필요한 경우 정부디렉터리시스템 표준 API의 승인 또는 별도 공식 인사정보 API가 필요합니다. 현재 정적 조직도 목록의 기준일과 최신 개편 여부는 화면에서 확인해야 합니다.

## 6. 예외 처리 및 테스트

- API 키 미등록·발급처 간 잘못된 키 중복·서버 오류·시간 초과·빈 응답을 구분해 안내합니다.
- RSS 일부가 실패해도 다른 피드를 표시합니다. RSS 응답은 시간 제한과 크기 제한을 적용합니다.
- `Quiz.txt` 또는 `NEWS.txt`가 없거나 형식이 잘못된 경우 해당 파일 관련 안내를 표시합니다.
- 엑셀 코드가 비어 있거나 이름을 찾지 못하면 잘못된 코드를 임의로 만들지 않고 직접 확인하도록 안내합니다.

회귀 테스트 실행:

```bash
python -m pip install -r requirements.txt
python -m pip install pytest
python -m pytest -q tests/test_core.py
```

`tests/test_core.py`는 개발·검수용이며 Streamlit Cloud에서 자동으로 실행되는 앱 파일이 아닙니다. 모의 테스트 통과는 실제 API·RSS·VWorld 타일·브라우저 UI의 실연결 성공을 뜻하지 않습니다. 실제 인증키를 이용한 API 호출과 Streamlit Cloud 브라우저 화면은 배포 후 별도로 확인해야 합니다.
